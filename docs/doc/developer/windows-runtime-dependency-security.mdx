# Windows Runtime Dependency Review

This note gates the PR 8404 split branches that add runtime, native, updater, or model-download behavior. It is a review checklist, not an approval record.

## Scope

Use this before landing the BYOK, local agent/Pi, local STT/TTS, or updater/package splits. The UI/Rewind split should not depend on these packages.

## Required Review Checks

- Confirm package provenance, license, and maintainer ownership for every new dependency and its native/transitive runtime packages.
- Record installer and unpacked app size deltas for each split branch, not just the integration branch.
- For runtime downloads, require explicit user opt-in before network/model download and pin release URLs with checksum validation before merge.
- Ensure every native or downloaded runtime has a clear unavailable state and falls back to hosted Omi behavior without crashing.
- Keep `resources/app.asar.unpacked` limited to files that must be outside asar, and verify paths on real Windows.
- Ensure BYOK/local keys and runtime tokens are never included in logs, analytics, crash reports, update metadata, or test fixtures.
- Keep dependency changes out of the UI/Rewind PR. Land package/runtime additions only in the branch that needs them.
